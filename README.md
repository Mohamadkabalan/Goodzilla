# Goodzilla

A static front-end prototype of a multi-vendor marketplace ("buy, sell and deliver") with separate flows for buyers, sellers and suppliers (2019). It is hand-coded HTML, CSS and jQuery: no back end, and all data is placeholder content.

This was a two-person project. I built the first landing-page version and the responsive Bootstrap home-page menu; a collaborator (Anthony Tahtouh) built most of the remaining pages.

## Pages

- **Storefront:** `index.html` (home with slider, categories, featured items, deals), `categories.html`, `product.html`, `my cart.html`, `checkout.html`, `thank you page.html`
- **Accounts:** `login.html`, `Sign up.html`, `congrats.html`
- **Marketplace roles:** buyer, seller and supplier registration and overview pages, plus `certified seller.html` and `certified supplier.html`
- **Admin mock-up:** `admin.html`
- **Content:** `About Us.html`, `services.html`, `Contact us.html`

## Stack

HTML5, CSS3, jQuery, Bootstrap 3.4 and Font Awesome 5 (via CDN), Swiper and Jssor sliders.

## Running

Open `index.html` in a browser, or serve the folder with any static file server.

## Structure

```
*.html       One file per page
css/         Page stylesheets and web fonts
js/          Page scripts and libraries
images/      UI and placeholder product images
```
